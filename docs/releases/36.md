# OurHouse release 36

Receipt stock quantities no longer disappear when an explicit discount sits between a product and its quantity/rate line. The parser compares the rate with the neighboring printed product totals. A unique match restores the supported quantity; a match to both products leaves stock unchanged and asks the user to check the photo. Headings, returns and sale notices remain boundaries.

Partial BOB basket counts remain separate from whole-receipt item counts, avoiding false missing-item warnings on warehouse receipts. A printed whole-receipt count still triggers review when it does not match the extracted purchased units.

This release contains parser corrections only. Receipt model, photo preparation, sign-in, household APIs, database schema and existing stored data remain compatible. Experimental model training and angle-correction work are excluded. It does not establish complete or instantaneous receipt recognition.
