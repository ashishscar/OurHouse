# Release 32 — receipt reader

Optional dedicated Cloudflare receipt transcription, with an explicit photo-processing opt-in. Photos and raw text are never logged or committed. Inference uses a fixed model, no tools, bounded JPEG input/output, account/household authorization, post-inference membership rechecks and hashed daily usage counters. Provider failures switch the whole scan to on-device reading; partial AI results are not imported.

Long photos are split into bounded overlapping sections. On-device layout compensates for measured text slope. Adjacent AI sections use boundary sequence matching without deduplicating product names inside a section. Review is capped at 500 products and image plans at 64 sections, with explicit warnings/limits rather than silent truncation.

Multiline count/rate rows preserve count × pack size. Pounds and ounces convert to pantry kg/g while the printed pack description remains in review. Monetary totals and printed unit counts are reconciled and discrepancies remain warnings for human review, never invented products. Nothing is selected or saved automatically.

Receipt import markers identify individual source rows, so a later review can add missing products without replaying previously added rows. Existing whole-receipt markers still protect exact matching products from old imports; changed product names require review.

A three-entry, account/household-bound in-memory scan cache avoids re-reading an identical photo. It is cleared when the account is locked or changed. Reading progress appears immediately; actual extraction still depends on photo size, device, model and connection. It is not guaranteed to be instantaneous.

Migration: apply 0006_receipt_ai_budget.sql to the existing production D1 only after isolated staging passes. It adds a technical counter table and does not modify household records or keys. Keep all model/data examples synthetic in the public repository. The user-supplied real receipt is used only for private manual verification, not model fine-tuning or a public fixture.
