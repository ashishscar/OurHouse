# Release 38 candidate: receipt quantities and conservative German routing

This release improves receipt review without changing the OurHouse URL, accounts, database, keys, storage or notification bindings. It has no data migration.

The parser reads a package size joined to the last product word and a following `weight × EUR/kg` line only when the arithmetic matches the separately printed item amount. It keeps the original receipt line for review and keeps a standalone discount heading out of the next item name. Common German food compounds and meat terms now guide Pantry routing; an exact HARIBO MAOAM Kracher match stays out of vegetarian stock because the maker lists gelatin. Users still review and select purchases before import.

On one opened 12-purchase public receipt, the experimental local OCR and parser read 12 purchase rows, 12 amounts and 12 stock quantities, and 11 categories matched the original frozen reference. That reference incorrectly put gelatin candy in the vegetarian Pantry; the scanner now excludes it. The original reference and correction remain private. This is not independent accuracy evidence. The experimental trained OCR model remains unshipped; names still contain OCR errors, and end-to-end phone latency is unmeasured.

The exact release source must pass local validation, isolated staging, rollback dry run and public smoke checks before promotion. The previous public release is 37.
