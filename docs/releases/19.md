# OurHouse web release 19

Adding a dish now focuses on its name, suggestions, serving count and ingredients. Cooking steps, family notes, icon, starter ingredients, history and sharing sit in optional sections. Save stays anchored at the bottom. The editable portion percentage is removed; new dishes start at the normal baseline and editing leaves the current learned factor and concurrent meal feedback untouched.

Selecting an online suggestion rounds weight/volume amounts, converts sub-unit kilograms/litres into practical grams/millilitres, and displays common cooking fractions such as ½ and ⅓. Ingredient inputs accept fractions and decimals. Tiny positive amounts are never rounded to zero. Manually entered, file-imported and existing saved quantities are not silently rounded. An untouched fraction display retains the original stored numeric value.

All 121 automated tests, TypeScript, the production build and Wrangler dry run passed. Validation covers suggestion rounding through the actual selection flow, fraction parsing, invalid values, exact saved-quantity preservation and concurrent meal feedback. Browser checks used only a disposable household. A real Wikibooks Swaminarayan recipe was selected, saved and reopened with its source credit, cooking steps, 13 ingredients and readable quantities. The form fits a 390px viewport without horizontal overflow; Save remains visible.

No database migration, role change, provider change, data reset or key rotation is included. Existing users keep their URL and accounts. Existing pages continue until reopened/refreshed.
